# ReportNic - Health-Tech Platform

A digital health platform prototype developed collaboratively during the **Hackathon Nicaragua 2024**. The project focuses on improving the accessibility and management of healthcare data through a user-friendly interface.

## Project Scope
- Fast-paced agile development during a hackathon environment.
- Cloud database integration for real-time data handling.
- Focus on UI/UX for healthcare accessibility.

## Tech Stack
- JavaScript / TypeScript
- Cloud Database (Firebase Firestore)
- Git & GitHub (Collaborative version control)

## Status
This project was built as a proof-of-concept for the 2024 competition edition.
